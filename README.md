<h1 align="center" id="title">clsInputValidate</h1>

<h2>🚀 Overview</h2>
Developed a reusable input validation library in C++ to ensure safe and consistent user input handling in console applications. Supports validation for data types such as integers, floats, strings, dates, and ranges, with customizable prompts and error messages.

<h2>🛠️ Installation Steps:</h2>
<p>
  1. Prerequisites 
  <li> visual studio.</li>
</p>

<p>2. Clone the repository</p>

```
git clone https://github.com/ZakariaAl-honyny/clsInputValidate.git
```
<p>3. go to `clsInputValidate.sln` file and press it to open project</p>
<p>4. build the solution and run it </p>
